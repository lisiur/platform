# 端云契约同步点（iOS ↔ 服务端）

客户端改动时必须同步检查的服务端/共享侧契约。漏改的共性症状是**静默**（缺行、错位、两端数字对不上），不是报错。

## 模式清单

| 模式 | 规则 | 漏改症状 |
|---|---|---|
| 能力枚举双白名单 | 客户端可配置能力（可自定义的 tab、快捷字段胶囊等）若服务端有白名单，**新增时两端同步** | 自定义页静默缺行/缺项 |
| 筛选/统计口径一致 | 同一数字的多个端点（列表、汇总、图表）必须走**同一个** where 构造器/口径函数 | 两端数字对不上 |
| 回显字段不读回 | 服务端回显的窗口/时间字段若是 UTC 规范化值，**客户端不应读回当真**——本地窗口以本地时区为准 | 按窗口聚合的数字整体错位一个周期 |
| 月窗口时区 | 带时区的「月/日」聚合：客户端请求显式带 tz 偏移；日期键用本地日历分量拼，不用 UTC 往返 | 跨时区漂移 |
| 排序参数 | 服务端排序（如按金额）要带**确定性 tiebreak**（日期 + 序号/主键），否则分页错乱 | 列表翻页重复/丢行 |
| 配置白名单校验 | 客户端自定义配置（tab 排列等）服务端校验合法性；存量**非法配置整包回落默认**，不做半套修复 | 旧客户端升级后 UI 卡死在非法态 |
| 图标/符号表镜像 | 货币符号、枚举文案等在共享包单一来源，两端镜像同一份 | 两端 glyph/文案不一致 |
| 归档/只读语义 | 「归档」类状态约定为**只挡写、读零过滤**（或反之），写进注释并三处同步（repository/schema/客户端注释） | 半挡不挡的中间态 |

## 通用纪律

- 改任何一个口径前，先 grep 它的**全部挂载面**（客户端多页面复用同一行/同一卡时，改一处全端生效——反之亦然）。
- 契约同步点写进对应代码注释（服务端与客户端各留一笔「改这里必须同步那里」），比文档更靠近改动现场。
